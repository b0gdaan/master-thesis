# Резервная копия материалов магистерской работы

Подготовлена 9 октября 2026 года перед переустановкой Windows. Основной проект, его финальная публичная PDF-версия и исходники сохранены в корне этой ветки на основе коммита `1fe8f4e9be05151b4bde0711eccf1c54f1fc5941`.

Перечень `manifest.json` сохраняет **6064 исходных путей**. Снимок содержит **1708 уникальных файлов**, 425.8 МиБ. Повторяющиеся файлы с одинаковой SHA-256 хранятся один раз. Все материалы снимка находятся в этой папке, независимо от файлов рабочего проекта в корне. Преобразование переносов строк Git отключено для этой папки, чтобы сохранить исходные байты при клонировании на другой операционной системе. Оригинальные названия и расположение всех включённых материалов восстанавливаются по перечню.

## Что сохранено

- Текущий проект из `D:\clear`: код, ноутбуки, настройки, исходные и обработанные рыночные данные, прогнозы, результаты, таблицы, рисунки, презентация и публичные тексты выступления.
- Связанный проект Thesis Copilot: исходники и материалы, прошедшие проверку публичной пригодности; локальная среда Python и воспроизводимый индекс исключены.
- Старые версии из `D:\архив\starye-versii-magisterskoy`, копия с другого компьютера, копия от 19 июля, русские переводы и историческая презентация PowerPoint.
- Комплект `research_blueprint` для следующей исследовательской работы.

Исходные файлы на компьютере не удалялись и не перезаписывались.

## Восстановление после переустановки

```powershell
git clone --branch ms/backup-before-windows-2026-10-09 --single-branch https://github.com/b0gdaan/master-thesis.git
cd master-thesis
python backup/2026-10-09/restore_backup.py
python backup/2026-10-09/restore_backup.py --output D:\thesis-recovered-2026-10-09
```

Первая команда Python проверяет SHA-256 каждого сохранённого файла. Вторая проверяет и создаёт новую папку с полной структурой включённых материалов. Существующую папку восстановления скрипт не перезаписывает. Для восстановления нужна только стандартная библиотека Python, без зависимостей проекта.

`current/` содержит снимок актуальных локальных материалов; `archive/` — прежние версии. Поле `stored` в перечне позволяет открыть нужный оригинал прямо в GitHub. Рабочая версия программы по-прежнему находится в корне репозитория.

## Что не опубликовано

В соответствии с выбором автора сохранены только материалы, пригодные для публичного репозитория. Подписанные заявления и согласия, личные университетские формы, частные заметки защиты и локальный журнал переписки исключены. В трёх печатных PDF страница официального решения университета удалена из отдельной публичной копии; все остальные страницы проверены на сохранение текста. Оригинальные PDF остаются локально. Среды Python, Git-метаданные, кэши, временные файлы сборки и материалы других проектов не включены. Файлы с возможными учётными данными исключены до ручной проверки.

Эта копия не является резервной копией всего диска D: или личных документов. Неопубликованные личные файлы необходимо отдельно сохранить перед форматированием диска. Полный перечень исключений оставлен локально в `D:\clear\thesis-backup-audit-20261009.json`.
