## 2. Установка LaTeX (MiKTeX) — если понадобится на новом ПК

На этом компьютере LaTeX не было вообще. Обычный `basic-miktex-x64.exe` (GUI-инсталлятор с `--unattended`) в этой автоматизированной среде не сработал — тихо завершался, ничего не ставя. Рабочий способ:

```powershell
# 1. Скачать компактную утилиту командной строки (не GUI-инсталлятор!)
# https://miktex.org/download -> "MiKTeX Setup Utility" (miktexsetup-*.zip)
# распаковать miktexsetup_standalone.exe

# 2. Скачать пакеты в локальный репозиторий
miktexsetup_standalone.exe --quiet --package-set=basic download --local-package-repository=C:\miktex-repo

# 3. Установить для текущего пользователя
miktexsetup_standalone.exe --quiet --shared=no --modify-path=yes --package-set=basic install --local-package-repository=C:\miktex-repo
```

**Важный нюанс, специфичный именно для этой сессии:** в моей (агентской) сессии PowerShell/Bash работал с правами администратора, из-за чего `miktex.exe links install` (создание exe-обёрток вроде `pdflatex.exe`, `biber.exe`) отказывался работать («must be run in admin mode» — как ни странно, наоборот). Пришлось руками делать hard-link'и:

```powershell
$bin = "$env:LOCALAPPDATA\Programs\MiKTeX\miktex\bin\x64"
New-Item -ItemType HardLink -Path "$bin\pdflatex.exe" -Target "$bin\miktex-pdftex.exe"
New-Item -ItemType HardLink -Path "$bin\biber.exe" -Target "$env:LOCALAPPDATA\Programs\MiKTeX\executables\windows-x64\biber\biber.exe"
```

**Если ты просто устанавливаешь MiKTeX обычным способом под своим обычным (не-админским) пользователем — этой проблемы почти наверняка не будет**, и `pdflatex`/`biber` появятся сами. Пробуй сначала стандартно, к этому костылю прибегай только если `pdflatex`/`biber` не находятся после установки.

Компиляция диплома (из папки `thesis/`):
```
pdflatex -interaction=nonstopmode main.tex
biber main
pdflatex -interaction=nonstopmode main.tex
pdflatex -interaction=nonstopmode main.tex
```
