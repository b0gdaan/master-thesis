## 🔬 Featured Projects

### 📈 [Master's Thesis — Intermarket ML Forecasting](https://github.com/b0gdaan/master-thesis)
Forecasting time-varying dependencies between Bitcoin and traditional financial assets (S&P 500, Gold, USD).  
Walk-forward ML pipeline (XGBoost, Ridge, ElasticNet, Random Forest) benchmarked against DCC-GARCH.  
**Result:** ML statistically outperforms econometric baseline — Diebold-Mariano test, p < 0.01.  
`Python` `XGBoost` `scikit-learn` `statsmodels` `arch` `walk-forward CV` `DM-test`

ETL pipelines from Wildberries & Ozon APIs → PostgreSQL → FastAPI → React dashboard.  
`FastAPI` `PostgreSQL` `ETL` `React` `Nginx` `Ubuntu` `REST APIs`
