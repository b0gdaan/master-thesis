📈 Thesis Copilot

Ask a master's thesis anything — and get answers grounded in the text, with page citations.

🚀 Live demo ⌨︎ Source on GitHub 📄 The thesis

The live demo runs on Hugging Face Spaces. First load builds the search index (~1–2 min), then it's instant.

What it does

Ingests

Reads the 76-page thesis PDF + defense Q&A, splits it into overlapping chunks, and stores local embeddings in Chroma — keeping page numbers for citations.

Retrieves

Finds the most relevant passages for any question in English, Serbian, or Russian — the question and the thesis need not share a language.

Answers

Generates a concise, cited answer with an LLM. With no API key it returns the top passages instead — semantic search runs fully offline.

How it works

PDF + page no.→ chunk→ embed (multilingual)→ Chroma→ top-k retrieve→ LLM + context→ answer + citations

Stack

Python LangChain Chroma sentence-transformers PyMuPDF Groq LLM Streamlit

Cross-lingual retrieval

A Russian or Serbian question finds the right English passage:

QuestionTop source found
Which model had the best RMSE?thesis.pdf p.29 — model-ranking table
Why does DCC-GARCH perform worst?defense_script.md — “Why is DCC-GARCH weaker here?”
Почему простые модели обошли сложные? (RU)defense_script.md — “Why are simple models better than complex ones?”

Run it locally

git clone https://github.com/b0gdaan/thesis-copilot
cd thesis-copilot
py -3.11 -m venv .venv && .venv\Scripts\activate
pip install -r requirements.txt
python ingest.py
streamlit run app.py

Optional generated answers: drop a free GROQ_API_KEY into .env (see .env.example).
